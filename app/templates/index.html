Integration Instructions

Setting up Webhooks

Wire up your repository to enable fully automated, real-time code reviews directly inside your pull requests.

GitHub Integration

  1. Navigate to your GitHub Repository → Settings → Webhooks → Add webhook
  2. Set the Payload URL to your active endpoint webhook route:
    http://your-server-domain/webhook
  3. Configure the Content type exactly to:
    application/json
  4. Select the event trigger type: Let me select individual events, check Pull requests, and uncheck other events.
  5. Check Active and submit.

GitLab Integration

  1. Navigate to GitLab Project → Settings → Webhooks
  2. Set URL to:
    http://your-server-domain/webhook
  3. Under triggers, check Merge request events and submit.
